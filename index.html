A desktop vision system with room for uncertainty—and a way for the user to correct it.

I built a native application that detects cats, classifies behavior, and records transitions in a session timeline. Inference runs in a worker to keep the interface responsive.

A validation-selected confidence margin lets the model withhold ambiguous predictions. Corrections save a frame and structured feedback locally.

Explore walkthrough ↗

Scripted browser demo; no camera access or live inference.

Model evaluation & technical notes +

A frozen MobileNetV3 encoder feeds a class-balanced ridge classifier over pooled visual features. On 543 held-out MEOW-10K clips, it achieved 37.9% accuracy against a 19.0% majority baseline. These dataset results do not establish live-camera accuracy.

Feedback is saved explicitly and does not automatically retrain the model. A separate earlier CLI pipeline handles rule-based events and optional AWS storage and notifications.

Python / PyTorch / YOLOv8 / PySide6 / OpenCV

Helping neighbors connect the dots around stray and missing cats.

THE INTERESTING PART

Rescue guidance & implementation notes +

The rescue assistant provides predefined guidance with optional Claude responses. Emergency vet information comes from OpenStreetMap with a fallback list. Matching is deterministic, not machine learning.

This is a development-stage application; authentication and access policies still need production hardening.

Match Tracker

Five leagues. One place to follow them.

Fixtures & resultsMatch historyTeam formElo estimates

From a La Liga tracker to a platform connecting fixtures, standings, and team insights.

A React dashboard sits on a modular Flask API that brings together match data, players, lineups, and news from multiple providers.

SQLite retains match history beyond the provider’s rolling window. Caching reduces repeated upstream requests, while chronological results feed team-form analysis and an Elo model.

Live site ↗Source ↗
Data sources & model limitations +

Provider clients combine football-data.org, API-Football, FotMob lineups, and Google News RSS. Backend pytest and frontend Vitest suites run in GitHub Actions.

The Elo model processes the previous 90 days of completed matches, with a fixed home-advantage adjustment. Its estimates are two-way and do not include a separate draw probability; predictive accuracy has not been validated.

React / Flask / SQLite / REST APIs / pytest / Vitest
