Catwatch / reproducibility note

How the behavior models were evaluated.

This page travels with the static portfolio demo. It summarizes the evaluated experiments without bundling source video, model weights, private camera feedback, or requiring GitHub access.

The desktop app uses the MEOW-10K checkpoint. The A2D experiment is a separate research model. The two results use different labels and splits, so they are not a head-to-head comparison.

Shared approach

  • Frozen ImageNet MobileNetV3 Small visual encoder.
  • Class-balanced ridge-regression classifier fitted on extracted clip features.
  • Candidate pooling modes and ridge strengths selected using validation macro-F1 only.
  • Held-out test results reported after selection, alongside a training-majority baseline.
  • Ridge decision scores are not calibrated probabilities.

MEOW-10K desktop model

The project selected 3,575 unique clips with sufficiently supported visually observable labels, merged into climbing, eating, grooming, jumping, lying/resting, playing, sitting, and walking. Rows inferred to originate from the same source video were assigned to one SHA-256 group split: 2,496 training, 536 validation, and 543 held-out test clips. Exact content duplicates across splits were rejected.

The selected configuration averages four uniformly sampled frame features and uses ridge alpha 1000. On the held-out test set it achieved 37.9% accuracy and 0.333 macro-F1, compared with a 19.0% majority baseline.

A top-two score-margin threshold was selected on validation for a 65% selective-precision target. On the untouched test set, it accepted 91 of 543 clips (16.8%) at 59.3% accuracy among accepted clips. This is an abstention mechanism, not proof that unknown behaviors are detected.

A2D research experiment

This separate six-label task uses climbing, eating, jumping, rolling, running, and walking. It contains 620 domestic-cat primary-action clips: 397 training, 101 validation, and 122 test clips. Official test sources were preserved; 20% of official training sources per class formed validation using a deterministic seed.

The selected configuration averages 12 sampled frame features and uses ridge alpha 100. On the official held-out test split it achieved 62.3% accuracy and 0.616 macro-F1, compared with a 17.2% majority baseline.

Important limits

  • These are clip-level dataset results, not live-camera accuracy.
  • Whole-frame features can exploit scene or background cues; the selected model does not learn frame ordering.
  • Source grouping and exact duplicate checks do not prove independent cat identities or eliminate near duplicates.
  • MEOW-10K labels are a project-specific merged visual taxonomy, not an official benchmark or verified current-action ground truth.
  • The A2D dataset is restricted to noncommercial scientific research.

Reproduce the public snapshot

After generating the local experiment reports, run:

python scripts/export_demo_results.py

This writes the aggregate snapshot used in the portfolio demo. Its report hashes, split counts, and model settings are visible in evaluation.json.
