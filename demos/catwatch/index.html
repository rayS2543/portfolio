Behind the interface

Three connected engineering problems.

01 / PERCEPTION

Find the cat. Build context.

YOLOv8s presence gating and overlapping-box suppression feed a rolling four-frame MobileNetV3 feature window. A three-second presence hold tolerates brief missed detections.

02 / DECISION

Learn a label. Allow uncertainty.

A class-balanced ridge head predicts eight dataset labels. A top-two margin threshold, chosen on validation data, lets the runtime abstain when the scores are too close.

03 / FEEDBACK

Let a person correct the model.

The PySide6 shell exposes Start/Stop, a session timeline, exact-label corrections, and rejection-only feedback. Each explicit feedback click saves one local example.

Two runtime paths, clearly separated.

The original CLI still supports heuristic behavior events, cross-camera cooldowns, AWS storage, and ntfy alerts. The trained desktop model is a local research preview; its predictions do not drive those alerts.
