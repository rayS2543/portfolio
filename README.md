# Raymond — Portfolio

A local, static software-engineering portfolio with an original canvas animation, project case studies, background, experience, and contact links. No build step or JavaScript dependencies.

## Preview

Run `python3 -m http.server 4173 --bind 127.0.0.1` from this directory, then open http://127.0.0.1:4173/.
